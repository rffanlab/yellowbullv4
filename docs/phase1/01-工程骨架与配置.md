# 01 · 工程骨架与配置（WP1）

> 工作包：搭建项目骨架、依赖管理、配置系统、日志、CI 与入口命令。
> 依赖：无（所有其他包的前置）。
> 上游：[Phase 1 总览](./README.md)

## 1. 目标

- 干净机器上 `uv sync` 后，`lh --version` 立即可用。
- 配置可加载、可校验、报错友好（缺 key / 字段错，给出"该改哪一行"的提示）。
- 日志统一、可脱敏、落盘。
- CI 跑 lint + 测试（不依赖真实 API）。

## 2. 技术选型（已定）

| 项 | 选择 | 版本基线 |
|----|------|----------|
| 语言 | Python | ≥ 3.11 |
| 包管理 | `uv`（备选 poetry） | uv ≥ 0.5 |
| 依赖声明 | `pyproject.toml`（PEP 621） | — |
| TUI | `textual` + `rich` | textual ≥ 0.50 |
| LLM 网关 | `litellm` | 锁定 minor 版本 |
| Web 抓取 | `httpx` + `beautifulsoup4`（+ `lxml`） | httpx ≥ 0.27 |
| 配置 | `pydantic` + `pydantic-settings` | pydantic v2 |
| 测试 | `pytest` + `pytest-asyncio` + `pytest-cov` | — |
| Lint | `ruff` | — |
| 类型 | `mypy`（先开，逐步收敛） | — |

> **依赖锁定**：`litellm`、`textual` 这类"行为敏感"依赖在 `uv.lock` 锁版本；升级走单独 PR 并跑全量 e2e。

## 4. pyproject.toml（要点）

```toml
[project]
name = "yellowbull"
version = "0.1.0"
description = "老黄牛 — 通用型 AI 工作助手（Phase 1 MVP）"
requires-python = ">=3.11"
dependencies = [
  "litellm>=1.40,<2",
  "textual>=0.50",
  "rich>=13",
  "httpx>=0.27",
  "beautifulsoup4>=4.12",
  "lxml>=5",
  "pydantic>=2.6",
  "pydantic-settings>=2.2",
]

[project.optional-dependencies]
dev = ["pytest>=8", "pytest-asyncio", "pytest-cov", "ruff", "mypy", "respx"]

[project.scripts]
lh = "yellowbull.__main__:main"

[tool.ruff]
line-length = 100
target-version = "py311"

[tool.pytest.ini_options]
asyncio_mode = "auto"
addopts = "-m 'not llm'"          # 默认跳过真实 API 测试
markers = [
  "llm: 需要真实 LLM API（默认跳过，手动 -m llm 开启）",
]

[tool.coverage.run]
source = ["src/yellowbull"]
```

## 5. 配置系统

**两层配置**：
- `config.yaml`：行为配置（默认模型、白名单、预算、日志级别）——可提交。
- `.env`：密钥（`OPENAI_API_KEY` 等）——不提交，`.env.example` 提交。

**加载优先级**：环境变量 > `.env` > `config.yaml` > 内置默认。

**schema（pydantic）**：

```python
class Settings(BaseSettings):
    default_model: str = "gpt-4o"
    fallback_chain: list[str] = ["gpt-4o", "claude-3-5-sonnet", "gemini-1.5-pro"]

    workdir: Path = Path("./")
    allow_paths: list[Path] = ["./", "./data"]

    max_steps: int = 25
    max_tokens_per_turn: int = 8000
    max_runtime_seconds: int = 600
    tool_output_cap_chars: int = 20_000

    log_level: str = "INFO"

    model_config = SettingsConfigDict(env_file=".env", extra="ignore")
```

**友好报错要求**：
- 字段缺失/类型错 → 打印"字段名 + 期望类型 + 示例 + 在哪个文件"。
- 必填 key 缺失（如只配了 1 家但默认模型指到它）→ 启动时明确提示"请设置 `XXX_API_KEY` 或改用 `/model`"，而不是运行到一半 500。

## 6. 日志与脱敏（骨架层）

- 统一入口 `yellowbull.logging.setup(level)`。
- 控制台：`rich` 友好格式；文件：`data/logs/`，按天切分，保留 14 天。
- **脱敏过滤器**（WP6 提供实现，WP1 先留 hook）：对 `sk-...`、`Authorization`、`.env` 值、`api_key` 字段做掩码 `***`。
- 日志级别：`DEBUG` 记录完整 tool 参数，`INFO` 只记摘要。

## 7. 入口与自检

`lh` 命令行为：
- `lh` → 进入 TUI。
- `lh --version` → 打印版本。
- `lh --check` → 环境自检（Python 版本、依赖、至少 1 家 key、ripgrep 是否可用、workdir 可写），逐项打勾/叉并给修复建议。**这是 A14（10 分钟上手）的关键**。

## 8. CI（GitHub Actions）

- 触发：push / PR to `master`。
- 矩阵：`ubuntu-latest` + `windows-latest`。
- 步骤：`uv sync` → `ruff check` → `mypy`（先 warn 不 fail）→ `pytest -m 'not llm'` → 覆盖率报告。
- **禁止** CI 里跑真实 API（无 key、不花钱、可复现）。

## 9. 边界与约束

- 本包**不实现**任何 Agent 逻辑，只提供"能跑起来的壳"。
- 所有运行期产物落 `data/`，`data/` 进 `.gitignore`。
- 不引入重型框架（不装 LangChain 等），保持依赖最小。

## 10. 本包的坑

| # | 坑 | 现象 | 对策 |
|---|-----|------|------|
| W1-1 | Windows GBK 控制台打印 emoji/中文报错 | UnicodeEncodeError | 启动时 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`；日志统一 UTF-8 |
| W1-2 | `litellm` 拉起重型传递依赖，安装慢/冲突 | 安装失败 | 锁定版本；`uv.lock`；CI 验证干净安装 |
| W1-3 | `textual` 要求较新 Python，与 3.10 用户冲突 | 启动报错 | `requires-python = ">=3.11"` + `--check` 明确提示升级 |
| W1-4 | `.env` 被误提交 | 泄密 | `.gitignore` 含 `.env`；CI 加 gitleaks 扫描 |
| W1-5 | `data/` 路径在 Windows 大小写/相对路径问题 | 文件找不到 | 全用 `pathlib` + `resolve()`；禁止字符串拼接路径 |
| W1-6 | `pytest-asyncio` 模式配置错误导致 async 测试被跳过 | 假绿 | 显式 `asyncio_mode="auto"` + 至少 1 个 async 哨兵测试 |
| W1-7 | `lh` 命令名与其他工具冲突 | 命令被覆盖 | 文档说明；冲突时可改用 `yellowbull` 全名（`[project.scripts]` 双入口） |
