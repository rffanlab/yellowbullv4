# 05 · CLI 界面（WP5）

> 工作包：命令行 TUI。把内核产出的事件流渲染成"对话 + 工具卡片 + 确认弹窗"，提供斜杠命令与会话持久化入口。
> 依赖：WP3（内核事件）、WP4（工具）、WP1（配置/日志）。
> 上游：[Phase 1 总览](./README.md) · [03 内核事件模型](./03-ReAct内核.md)

## 1. 目标

- `lh` 启动即进入可用 TUI（A1：≤5s 冷启动到可输入）。
- **只消费内核事件、只发用户意图**，不含任何 Agent 逻辑（渲染层零智能）。
- 流式平滑（K10）、中文/emoji 不错位、小窗口（80×25）不崩。
- 危险操作确认弹窗（A4）、Esc/Ctrl+C 语义清晰（A10/A15）。
- 会话可保存/恢复（`/resume`），历史可查（`/history`）。

## 2. 技术选型（已定）

| 项 | 选择 | 说明 |
|----|------|------|
| TUI 框架 | `textual` | 纯 Python、跨平台、组件化、支持流式更新 |
| 富文本 | `rich` | 内核/文本渲染复用 |
| 输入 | `textual.Input` + 自研斜杠命令补全 | 不额外引 prompt_toolkit，统一在 textual 内 |

> 放弃"裸终端 + prompt_toolkit"方案：流式渲染、弹窗、多面板在 textual 里更可控（总览 D4）。

## 3. 界面布局

```
┌──────────────────────────────────────────────────────────┐
│  老黄牛  ·  模型:gpt-4o  ·  会话:s2026-08-15-a1b2        │  ← 头部
├──────────────────────────────────────────────────────────┤
│  ▍你：帮我写个脚本统计 sales.csv 并按月汇总                │
│  ▍老黄牛：好的，我先看一下文件结构。                        │
│  ┌─ 工具 card ────────────────────────────────────────┐  │
│  │ 📄 file_read  sales.csv                [成功 0.2s] │  │
│  │   参数: path=sales.csv  limit=2000   (展开▶)       │  │
│  └────────────────────────────────────────────────────┘  │
│  ┌─ 工具 card ────────────────────────────────────────┐  │
│  │ ⚡ run_python  stats.py            [需确认]         │  │
│  │   ▸ 将执行: python stats.py   (60s 超时)            │  │
│  │        [ y 执行 ]  [ n 取消 ]  [ a 本次都允许 ]      │  │
│  └────────────────────────────────────────────────────┘  │
│  ▍老黄牛：统计完成，产物在 data/artifacts/…/monthly.csv   │
├──────────────────────────────────────────────────────────┤
│  > _                                                    │  ← 输入框
│  tokens:12.3k  步数:4/25  预算:OK   /help 查看命令        │  ← 状态栏
└──────────────────────────────────────────────────────────┘
```

**面板**：
- 主消息流（滚动）：用户输入、模型正文、工具卡片。
- 工具卡片：折叠（默认显示名+状态+耗时）/展开（参数+结果摘要）。
- 确认弹窗（内联卡片式，非模态，便于上下文可见）：`y/n/a`。
- 状态栏：当前模型、会话 ID、token 用量、步数、预算状态。

## 4. 交互与事件映射

| 内核事件 | CLI 渲染 |
|----------|----------|
| `ThinkingDelta` | 追加到当前"老黄牛"气泡（流式） |
| `ToolStart` | 新建工具卡片（运行中动画） |
| `ToolConfirm` | 卡片进入"需确认"态，激活 y/n/a 快捷键 |
| `ToolResult` | 卡片更新为 成功/失败 + 摘要 + artifact 路径 |
| `ToolError` | 卡片红色 + 错误信息 |
| `ModelFallback` | 状态栏提示 + 一条系统消息 |
| `Final` | 收尾气泡 + 产物清单（可点击复制路径） |
| `Aborted` | 灰色系统消息 + 原因 + 建议 |

**流式渲染策略（K10）**：
- 用 `rich` 的 `Live` 区域或 textual 的 `refresh`，**节流到 ~30fps**，批量合并增量，避免每 token 全量重绘。
- 大段文本分块追加，滚动锚定底部（除非用户在向上看历史）。

## 5. 斜杠命令

| 命令 | 作用 |
|------|------|
| `/help` | 命令与快捷键帮助 |
| `/model [name]` | 查看/切换模型（列出能力表，联动 WP2） |
| `/tools` | 列出可用工具 + 风险级别 |
| `/clear` | 清空当前会话上下文（不删审计） |
| `/history` | 列出历史会话（ID+时间+首句） |
| `/resume <id>` | 恢复某次会话继续 |
| `/status` | 当前会话 token/步数/预算/模型 |
| `/approve` | 对当前待确认操作放行（等价 y） |
| `/exit` | 退出 |

**快捷键**：
- `Enter` 发送；`Esc` 中断当前任务（A10）；`Ctrl+C` 第一次=中断、第二次=退出（A15）；`y/n/a` 确认；`Ctrl+L` 清屏保留会话。

## 6. 会话持久化

- 每个会话一个目录 `data/sessions/<id>/`：`audit.jsonl`（内核写）+ `meta.json`（CLI 写：标题、模型、时间、产物清单）。
- `/clear`：新建会话 ID，旧会话保留可 `/resume`。
- 恢复：读 `meta.json` + 最近上下文（Phase 1 恢复"上下文摘要"即可，不重放全部工具状态）。

## 7. Windows / 终端适配

- **首选 Windows Terminal**；`conhost` 下做降级：关闭动画、降低配色（`NO_COLOR`/`TERM=dumb` 检测）。
- 启动时 `sys.stdout.reconfigure(encoding="utf-8")`（联动 W1-1）。
- 中文宽度：用 `rich` 的 `cell_len` 计算，避免错位；emoji 用 `textual` 内置处理。
- 小窗口（80×25）：面板可折叠、工具卡片自动收窄，不允许横向溢出。

## 8. 边界

- CLI **不**判断权限、**不**执行工具、**不**拼 prompt；只渲染事件 + 收集用户输入/确认。
- 确认的"本次都允许"（`a`）粒度 = 当前任务内同类风险，**不做**跨会话全局放行（联动 WP6）。
- 不实现 Web/语音（Phase 3）。

## 9. 本包的坑

| # | 坑 | 现象 | 对策 |
|---|-----|------|------|
| K10 | 高频流式全量重绘 | 整屏闪烁、CPU 飙 | 节流 30fps + 增量追加 + `Live` 局部刷新 |
| C5-1 | 中文/emoji 宽度错位 | 换行错乱、光标漂移 | `rich.cell_len` 计算；避免自绘固定列宽 |
| C5-2 | conhost 不支持真彩色/动画 | 花屏、无动画 | 检测终端能力，降级配色/关动画 |
| C5-3 | Esc 与"中断输入"冲突 | 误中断任务 | Esc 仅在"有任务运行中"时中断；空闲时 Esc=清空输入 |
| C5-4 | Ctrl+C 双击语义 | 误退出/退不出 | 第一次置 cancel_event，1s 内第二次才退出；退出前 flush 审计 |
| C5-5 | 80×25 小窗口布局溢出 | 内容被裁/横向滚动 | 响应式面板 + 折叠；测试最小尺寸 |
| C5-6 | 流式中崩溃丢失会话 | 上下文丢 | 事件驱动渲染，状态在内核；CLI 崩溃重启可 `/resume` |
| C5-7 | 长 artifact 路径显示 | 溢出/不可读 | 路径截断显示 + 悬停/展开看全 + 一键复制 |
| C5-8 | 确认弹窗被新消息顶掉 | 用户没看到确认 | 确认态卡片固定可见，未处理前暂停追加新卡片 |

## 10. 验收（本包 DoD）

- [ ] Windows Terminal 下完整跑通"输入→思考→工具→确认→结果"流。
- [ ] 80×25 窗口布局不溢出、可折叠。
- [ ] 流式平滑无整屏闪烁（主观 + 简单帧率自检）。
- [ ] `y/n/a` 确认正确；`a`=本次任务内同类放行。
- [ ] Esc 中断运行中任务 ≤1s（A10）；Ctrl+C 两次退出无残留（A15）。
- [ ] `/model` 切换生效；`/tools`、`/status`、`/history`、`/resume` 可用。
- [ ] `/clear` 后上下文清空、旧会话可恢复。
- [ ] conhost 降级模式可用（配色/动画自适应）。
- [ ] 渲染层零 Agent 逻辑（代码评审 + 无 LLM/工具直接调用）。
